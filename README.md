# SmallTV-Utra-RU-EN-FW-dumps
Full EN/RU original firmware dumps of SmallTV Ultra

Main goal is get rid of shitty fw on SmallTV Ultra clones

ALWAYS MAKE FULL BACKUP OF ORIGINAL FW!  
DO NOT ATTEMPT FLASH VIA WEB UPDATE!  
FLASH ONLY WITH USB to TTL adapter!

After successful flash, you can freely update (ONLY FOR EN VERSION) to the [latest version](https://github.com/user-attachments/files/27423490/FW-Smalltv-Ultra-V9.1.54.zip)  
If your device stuck in bootloop, use [this script](https://github.com/GeekMagicClock/smalltv-ultra/issues/224#issuecomment-4936451679) and reflash fixed dump
